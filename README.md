# Voltix-EG Internship Projects

This repository contains projects and practical work completed during my internship at **Voltix-EG**.

The projects focus on data analysis, data visualization, and applying Python-based data science tools to real-world datasets.

##  Projects

### EzzSteel Sales Analysis

A sales data analysis project based on EzzSteel sales records.

The project focuses on:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Sales performance analysis
* Product and category analysis
* Regional analysis
* Data visualization
* Extracting meaningful business insights

 Project folder: [`EzzSteel-Sales-Analysis`](./EzzSteel-Sales-Analysis)
